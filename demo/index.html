ios-keyboard-focus

Opening the iOS on-screen keyboard for an input that does not exist yet. Each demo runs the same four scenarios, with a toggle to turn priming off so you can feel the bug it fixes.

These only mean anything on a real iPhone. Simulators and desktop Safari with a touch emulator both fail to reproduce the problem.

Vanilla

Plain DOM, no framework. primeKeyboard() and handover().
